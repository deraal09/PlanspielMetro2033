# Design (für spätere Oberfläche)

Dunkle Metro-Optik wie in der Papierversion. Es werden **keine** Grafiken oder Logos aus dem Videospiel Metro 2033 verwendet, nur eigene Motive.

| Zweck | Farbe |
|---|---|
| Akzent Amber | `#f2a900` |
| Akzent Rost | `#e8571f` |
| Hydroponiker (Grün) | `#2e7d32` |
| Wasserwerker (Blau) | `#1565c0` |
| Techniker (Orange) | `#b35f00` |
| Sanitäter (Rot) | `#c62828` |
| Wächter (Grau) | `#555a60` |

Die Gruppenfarben stehen auch in `src/regeln/config.js`. Hintergrund und Textfarben werden mit der Oberfläche festgelegt; dabei auf ausreichenden Kontrast achten (Gruppenfarben auf dunklem Grund prüfen).
